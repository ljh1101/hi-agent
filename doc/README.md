# hi-agent Documentation / 文档

- **English** → [en/README.md](en/README.md)
- **中文** → [zh/README.md](zh/README.md)

The two versions are mirrors of each other and are updated together: a
change to behavior, interfaces, defaults, safety boundaries, or file formats
must land in **both** `doc/en/` and `doc/zh/` in the same change (see
`AGENTS.md` → Documentation).

两个版本互为镜像、同步更新：行为、接口、默认值、安全边界或文件格式的
变更必须在同一次变更中同时落入 `doc/en/` 与 `doc/zh/`（见 `AGENTS.md`
的 Documentation 段）。
